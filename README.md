# Hard Neon: Triage

A small real-time healing game prototype set in the Hard Neon universe. You are the healer; keep a party of three
alive through a boss fight. Desktop only (keyboard + mouse).

**Play:** open `index.html` in a browser, or visit the GitHub Pages link for this repo.

## Controls
- Click a party frame or F1–F4 to target
- 1–8 cast abilities · Tab switch front/back line · Esc cancel · P pause

## Tuning
All numbers live in `data/*.js`, all text in `data/strings.js`. No build step.
Difficulty multipliers and the feedback-form link are in `data/settings.js`.
